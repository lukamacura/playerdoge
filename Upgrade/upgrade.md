Referral Program for Creators (YouTubers)
The Concept:
You are a YouTuber who has agreed to promote Kinged in exchange for a commission. But how do you track your referrals and total sales?

The Solution:
Transparency is key. We provide you with a Creator Code that is visible within our admin panel transactions. This allows creators to independently track their performance and sales in real-time.

User Experience & Workflow
In your video description, you’ll include a call to action:

"Use code MACURA on your first purchase to get a $5 package for free!"

Initial Purchase: The user visits the site and buys coins for the first time.

Reward Activation: After the purchase, the user becomes eligible for one free package (valued at 500 coins), provided they use a Creator Code.

Permanent Link: Once a Creator Code is applied, it is permanently linked to that user's account. Every future transaction they make will be flagged with your code in our admin panel.

UI Cleanup: Ideally, once a code has been successfully applied, the "Creator Code" input field should disappear from that user's purchase information box.

Automation & Logic
We want to automate the $5 free package delivery to ensure a smooth experience.

The Logic Challenge:
"How does the user receive the free package without the system deducting coins that I’d eventually have to manually refund?"

The Solution Constraint:
Eligibility for the free package is strictly tied to a prior purchase. To protect our margins, we cannot offer the $5 bonus for free to everyone; it must be a reward specifically for paying customers referred by a creator.
